Build a fully custom password-protected page from scratch — your own layout and design instead of WordPress's default plain password form.

== Description ==

Lockaire lets you design a fully custom password-protected page in WordPress. Unlike other password protection plugins that use WordPress's default plain password form, Lockaire gives you complete control — build your own layout, content, and branding using the shortcode on any page or post you create.

= Features =
* Password Protect specific pages and posts
* Redirect visitors to your custom password page
* AJAX-powered password validation
* Redirect users back to protected content after authentication
* Separate access control for pages and posts
* Password visibility toggle
* WordPress nonce security protection

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Create a new page and add the [lkar_password_protector_form] shortcode to it — this becomes your custom password page.
4. Go to Lockaire in your dashboard and configure: select your password page, the page or post to protect, and set a password.
5. Save your settings.

== Frequently Asked Questions ==

= How It Works =
1. A user visits a protected page or post.
2. The plugin redirects them to your custom password page.
3. The user enters the correct password.
4. Access is granted.
5. The user is automatically redirected back to the requested content.
